# 🚗 Mobility & Economy Analysis — 2024

## 📌 Descripción

Proyecto de análisis de datos que estudia la posible relación entre la **congestión vehicular** y diferentes **indicadores económicos** de ciudades alrededor del mundo.

El análisis se realizó utilizando información correspondiente al año **2024**, integrando datos de movilidad urbana y variables económicas por ciudad.

## 🎯 Objetivo

Analizar si existe una relación clara entre los niveles de **congestión vehicular** y el **PIB per cápita** de las ciudades, identificando posibles patrones y diferencias entre regiones.

## 🛠️ Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔎 Proceso de análisis

- Exploración y limpieza de los datasets.
- Estandarización de nombres de columnas.
- Conversión de variables numéricas y fechas.
- Filtrado de información correspondiente a 2024.
- Agregación de datos de tráfico por ciudad y año.
- Integración de los datasets mediante `INNER JOIN`.
- Análisis exploratorio y visualización de datos.
- Identificación de patrones y valores atípicos.
- Exportación del dataset final en formato CSV.

## 📊 Principales resultados

El análisis no muestra una **relación directa y clara** entre el PIB per cápita y la congestión vehicular.

Se encontraron ciudades con PIB elevado que no necesariamente presentan altos niveles de congestión. Por otro lado, algunas ciudades presentan una congestión considerable a pesar de contar con indicadores económicos más bajos.

**México** destaca por presentar altos niveles de congestión, mientras que **Bogotá** presenta una combinación de alta congestión y un PIB per cápita relativamente bajo.

Estos resultados sugieren que existen otros factores que pueden influir de manera importante tanto en la movilidad como en el desempeño económico de una ciudad.
